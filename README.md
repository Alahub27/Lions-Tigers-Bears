## Descriptions:
The project was created by using HTML and CSS. This projects is hosted on Micosoft Azure. This project was completed to create a slideshow of dog breed images fetched from a public API.

## Instructions: 

Open the index.html file in a web browser by opening it in Visual Studio Code and clicking Open in Live Server

Then, you click the dropdown button that says Choose a dog breed. Once you choose a dog breed, then images of the chosen dog breed will show in a slideshow style with fading transitions between each picture.
